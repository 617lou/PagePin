# Changelog

**[中文更新日志](CHANGELOG.zh-CN.md)**

Notable changes to PagePin, per version.

## 0.1.4 — 2026-08-06

### Improved

- **Annotation list layering and dragging**:
  - Annotation mode: the annotation list is raised to the top layer so numbered icons no longer overlap it; numbered icons still render above the remark dialog backdrop, so clicking another number while a dialog is open still switches in one click.
  - Viewing mode (exported files): the annotation list is layered above all numbered icons; the popup opened by clicking a number is raised to the top layer, above the annotation list.
  - In both modes, the annotation list can be dragged by its header (title bar) to any position to avoid blocking page content; the close button in the header keeps working as before.
- **Annotation list gets a maximum height (80% of the viewport).** With many annotations the list panel no longer stretches toward full-screen; content beyond the cap scrolls inside the list while the header and close button stay visible. Applies to both the extension and the exported viewer.

### Fixed

- **Re-annotations on exported files were lost after a refresh.** Annotations added with the extension on top of an exported `.annotated.html` lived only in page memory: a refresh lost them and clicking the extension icon could not restore them. They are now auto-saved to local storage keyed by page URL like any other page, and reopening the exported file restores the local record (it is newer than the data embedded in the file); a successful re-export clears it as before.
- **The numbered icon no longer disappears while editing an annotation.** Opening the remark dialog previously removed that annotation's numbered icon from the page, so you could not cross-check which element the remark belonged to. The icon now stays visible while the dialog is open.

## 0.1.3 — 2026-08-05

### Fixed

- **Clicking the dialog backdrop closed the remark dialog.** Clicking the blank area outside the dialog dismissed it and discarded whatever had been typed. The backdrop no longer closes the dialog; use **Cancel** or Esc instead.
- **Annotations were lost after navigating away or reloading.** Annotations lived only in the current page's memory and DOM, so an accidental link click, a reload, or the browser recycling the tab wiped them all. Annotations are now saved automatically to local browser storage keyed by page URL (hash stripped); reload or reopen the page and they are restored automatically, persisting until a successful export. Auto-restore covers local `file://` pages and `localhost` / `127.0.0.1` dev-server pages; other http(s) pages (no all-sites permission requested) still restore by clicking the extension icon.

### Changed

- **Annotations are cleared after a successful export.** Once the exported file downloads, the annotations on the page and the locally saved copy are removed (they are fully embedded in the exported file), so the next annotation round starts clean.
- **The annotation popup in the viewer now has a maximum height.** Long remarks no longer stretch the popup off-screen; content beyond the cap scrolls inside the popup while the header and close button stay visible.

## 0.1.2 — 2026-08-04

### Fixed

- **Clicking "Locate" in the annotation list sometimes required a second click.** The list was fully destroyed and rebuilt after any page DOM mutation (debounced 200 ms); if a rebuild landed between mousedown and mouseup, that click was lost. Buttons also captured the target element from render time, so after the page recreated an annotated element the first click silently did nothing. List items are now reused per annotation id (only text, status, and disabled state refresh), and "Locate"/"Edit" re-resolve the target element at click time. Fixed in both the extension and the exported viewer.
- **List text stayed stale after saving an annotation edit** until the next page DOM mutation; the list now refreshes immediately on save.

## 0.1.1 — 2026-08-04

### Fixed

- **Numbered icons sometimes required a second click** (annotation mode and exported viewer). All icon buttons were destroyed and recreated on every re-render (scroll/resize, and 200 ms after any page DOM mutation); if a re-render landed between mousedown and mouseup, the click was retargeted to a handler-less container and lost. Icon buttons are now reused per annotation id (only position and number update), and clicks re-resolve the target at click time.

### Changed

- Numbered icons render above the annotation dialog backdrop, so clicking another number while a dialog is open switches to it in one click.

### Added

- Extension icons (blue pushpin, 16/32/48/128 PNG) for the toolbar and extensions page, generated by the dependency-free script `tools/make-icons.js` — rerun it after tweaking colors or shapes.

## 0.1.0

Initial release.

- Element picker (DevTools-style hover highlight, click to annotate)
- Numbered icons (auto renumber after deletion)
- Annotation list with locate, edit, and delete
- Export as a self-contained annotated HTML — viewable without the extension
- Annotations kept in an in-page data node (current document only)
- Numbered icon visibility toggle
