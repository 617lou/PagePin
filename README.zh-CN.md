# PagePin

**[English](README.md)** | **[操作手册](manual.zh-CN.md)** | **[更新日志](CHANGELOG.zh-CN.md)**

一个 Chrome / Edge 浏览器扩展，用于在浏览器中为 HTML 页面的任意元素添加文字批注，并导出为独立的带批注 HTML 文件——任何人无需安装扩展即可查看。

## 为什么做这个

产品经理的交付物正在变化。过去原型工具（Axure、墨刀等）输出的原型自带元素级备注——开发、测试点开某个按钮，就能在原位读到这条需求说明，"看到什么就读到什么"，理解需求很快。

而现在，越来越多的交付物变成了**静态 HTML 原型 + 一份独立的 PRD**。页面只负责"长什么样"，需求说明都被收进了另一份文档。于是开发、测试看页面时，不得不在"页面上的这个元素"和"PRD 里描述它的那一段"之间反复对照。原本附着在元素上的备注消失了，理解成本被悄悄抬高。

PagePin 想把"备注"重新钉回它该在的地方——**直接附着在页面元素上，在原位可读**。

**秉持的原则：**

- **备注跟着元素走**：所见即所注，批注钉在具体元素上，而不是散落在另一份文档里。
- **零门槛、不侵入**：不挑原型来源，不需要服务端和账号，打开任意 HTML 即可批注；不改动原页面的语义。
- **交付物仍是单文件**：导出一份自带批注的独立 HTML，任何人无需安装任何东西就能查看，契合"HTML + PRD"的交付习惯。

**方便的人：**

- **开发、测试及相关评审人员**：在 HTML 原型上直接读到元素级备注，省去页面与 PRD 之间的来回映射。
- **产品经理 / 需求方**：无需回到原型工具，就能快速把说明钉到 HTML 上，并分享一份带批注的文件。

## 功能特性

- **元素选取** — 类似 DevTools 的悬停高亮，点击即可添加批注
- **序号图标** — 每条批注在目标元素上显示序号；删除后自动重新编号，不会断号
- **批注列表** — 侧边面板支持定位（滚动 + 高亮闪烁）、编辑、删除
- **自动保存** — 批注按页面网址自动保存到浏览器本地，误点跳转、刷新页面不丢失，重新打开页面自动恢复；导出成功后自动清除
- **动态页面支持** — MutationObserver 实时同步图标；CSS 选择器快照在弹窗元素销毁重建后自动恢复批注绑定
- **可拖动 UI** — 工具栏、查看器底栏可按住图钉图标拖拽，批注列表可按住头部拖动，避免遮挡页面内容
- **一键导出** — 下载独立的 `.annotated.html` 文件，内嵌全部数据和查看脚本
- **内置查看器** — 导出文件自带序号图标、单条批注弹窗、批注列表（定位 + 高亮），无需扩展

## 安装

1. 克隆或下载本仓库。
2. 打开 `chrome://extensions`（Chrome）或 `edge://extensions`（Edge）。
3. 开启 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选择项目根目录。
5. 如需批注本地 `file://` 文件，在扩展详情页开启 **允许访问文件网址**。

## 快速上手

1. 在浏览器中打开任意 HTML 页面。
2. 点击 PagePin 扩展图标 → 页面右下角弹出悬浮菜单。
3. 点击 **开始批注** → 悬停高亮 → 点击元素 → 输入批注 → **保存**。
4. 点击 **导出 HTML** → 保存 `.annotated.html` 文件。
5. 用任意浏览器打开导出文件即可查看批注。

> 批注按页面网址自动保存到浏览器本地：中途误点跳转、刷新页面都不丢失，重新打开页面即自动恢复（其他 http(s) 网页需点击扩展图标恢复）；导出成功后自动清除。

完整操作说明请参阅 **[操作手册](manual.zh-CN.md)**（[English](manual.md)）。
